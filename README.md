# ContentGen AI

AI content generation studio powered by MiMo V2.5.

## Features

- Writer-themed interface with warm tones
- Format tabs (Blog, Social, Email, Ad Copy, Technical)
- AI suggestion panel with rephrase/expand/summarize options
- Real-time word and character count
- Content export functionality

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES6+)
- No external dependencies or frameworks

## Usage

Open `index.html` in a browser. Choose a format tab, enter a topic, and generate AI content with suggestions.

## AI Engine

Powered by **MiMo V2.5** — Nous Research's content generation model.
