# ContentGen-AI

A fully functional, browser-based content generation platform that creates professional content using smart templates and randomization.

## Features

- **5 Content Types:** Blog Post, Tweet Thread, Marketing Email, Product Description, README.md
- **8 Industry Niches:** General, Technology, Healthcare, Finance, E-Commerce, Education, Fitness, Food & Beverage
- **5 Tone Options:** Professional, Casual, Witty, Persuasive, Informative
- **Word Count & Read Time** calculator in real time
- **Copy to Clipboard** with one click
- **Export as .md** file download
- **Responsive Design** — works on desktop and mobile
- **Zero Dependencies** — pure HTML, CSS, and JavaScript

## How to Use

1. Open `index.html` in any modern browser
2. Enter a topic or subject
3. Select content type, industry, and tone
4. Click **Generate Content**
5. Copy or export the result

## Tech Stack

- HTML5
- CSS3 (CSS Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
